<threat_model>
## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| daemon → spawned agent process | The child runs with the operator's shell on the operator's real machine |
| daemon → git remote | The deliverer pushes refs and opens pull requests on the operator's behalf |
| bot writes → ingress | Every comment the notifier posts is an event the loop guards must drop |

## STRIDE Threat Register

| Threat ID | Category | Component | Severity | Disposition | Mitigation Plan |
|-----------|----------|-----------|----------|-------------|-----------------|
| T-07-14 | Information disclosure | Spawned child environment | critical | mitigate | The run-path test asserts the child env carries neither secret; the worker owns all Linear I/O by design (04-CONTEXT D-15) |
| T-07-15 | Spoofing | Loop guard L1 with an unresolved bot id | high | mitigate | Task 2 resolves the bot id before ingress binds and the smoke asserts it is non-empty; an unresolved id disables the guard silently |
| T-07-16 | Tampering | Push to the default branch | critical | mitigate | The run-path test asserts the run's branch is not the repository default; the deliverer refuses outright and never force-pushes (04-CONTEXT D-13) |
| T-07-17 | Denial of service | Slot held by a blocked run | high | mitigate | The run-path test asserts full scheduler capacity while a run sits in `awaiting_answer` (06-CONTEXT D-02) |
| T-07-18 | Repudiation | A notification path that skips the log | medium | mitigate | The log channel is constructed inside the fan-out, not as a peer call site, and the notifier is reached only through the engine (05-CONTEXT D-04) |
| T-07-19 | Elevation of privilege | Constructor-time I/O reaching git or the agent binary | medium | mitigate | The smoke constructs every component offline; a constructor that touches the filesystem or PATH fails it |
</threat_model>
