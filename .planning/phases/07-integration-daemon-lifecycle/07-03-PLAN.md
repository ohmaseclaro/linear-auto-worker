<objective>
The tracer for this phase: one signed webhook travelling the whole ingress seam into a
persisted `queued` run, with the expensive half of the system still faked.

07-CONTEXT D-01 fixes this ordering and says why — a real delivery producing a queued run
while execution is faked proves the entire ingress seam while it is still cheap to
iterate on. Wire execution first and every ingress bug costs a full Claude session to
reproduce.

This plan also builds the boot smoke script, which 07-CONTEXT D-04 makes the phase's
central verification instrument. Typecheck cannot see a wiring break and unit tests
instantiate against fakes, so a module that never wires up what it depends on passes both.
Only something that actually boots catches it — and from this plan on, every remaining
plan in the phase verifies against it.

Purpose: prove the architecture end-to-end before the expensive layers land on top of it.
Output: `src/cli/daemon.ts`, `scripts/boot-smoke.ts`, an `npm run smoke` script.
</objective>

<threat_model>
## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| public internet → receiver | Once a tunnel exists, anything can POST to the bound port; only the HMAC separates Linear from an attacker |
| smoke run → operator config root | A test that writes to `~/.linear-auto-worker/` can destroy real run history |

## STRIDE Threat Register

| Threat ID | Category | Component | Severity | Disposition | Mitigation Plan |
|-----------|----------|-----------|----------|-------------|-----------------|
| T-07-09 | Spoofing | Webhook signature verification | critical | mitigate | The seam test asserts tampered and stale deliveries are refused with 400 and write nothing; the smoke signs over exact body bytes so a re-stringify regression fails the run (T6, T14) |
| T-07-10 | Denial of service | Tunnel opened before the bind | high | mitigate | The smoke's tunnel stub TCP-probes the port; a 502 window burns Linear delivery retries and moves the webhook toward auto-disable (HOOK-01) |
| T-07-11 | Tampering | Boot smoke writing to the real config root | high | mitigate | Smoke creates its own `mkdtemp` directory and is asserted to do so; it never reads `~/.linear-auto-worker/` |
| T-07-12 | Spoofing | Self-event loop | high | mitigate | Seam cases cover the bot-actor and null-actor drops and assert the named-guard counter climbs (03-CONTEXT D-08, D-09) |
| T-07-13 | Elevation of privilege | Child process spawn during smoke | medium | mitigate | The scheduler is not started in this plan and execution components are fakes; no path from a smoke delivery reaches a spawn |
</threat_model>
