<threat_model>
## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| spawned agent → worker | `parseAgentResult` is where the child process's stdout, which is untrusted attacker-influenceable text once a Linear issue body reaches the prompt, first becomes a typed value the worker acts on |
| operator config file → worker | The `Config` type is the shape Phase 2 validates against; a field defined here that the loader forgets to validate is a validation hole |

## STRIDE Threat Register

| Threat ID | Category | Component | Severity | Disposition | Mitigation Plan |
|-----------|----------|-----------|----------|-------------|-----------------|
| T-01-05 | Spoofing | `parseAgentResult` | high | mitigate | Narrow on the `status` discriminator and require each member's own fields before returning; throw `AgentResultParseError` on anything else. Never infer outcome from prose or from an exit code. A crafted issue body that steers the agent into emitting an arbitrary object cannot produce a value the worker treats as a completed delivery. |
| T-01-06 | Information Disclosure | `Config` | high | mitigate | No secret-bearing field is defined on `Config` (D-08). The two secrets live in a mode-0600 environment file beside config.json, so a `Config` value that reaches a log line or an operator's paste buffer carries no credential. Verified by a negative check over the `Config` declaration in Task 2. |
| T-01-07 | Tampering | `Store` interface | medium | mitigate | The interface exposes no raw-SQL escape hatch — only named methods — which keeps all SQL confined to the Phase 2 implementation and prevents a second writer to the run state growing in another layer. |
| T-01-08 | Elevation of Privilege | `AgentSpawnRequest.env` | medium | transfer | The port makes the child's environment an explicit, caller-constructed record rather than an inherited one, which is what lets Phase 4 withhold the daemon's secrets by construction. Enforcing that withholding is Phase 4's mitigation, not this plan's. |
| T-01-09 | Repudiation | `RunEvent` | low | accept | Emission is Phase 5's; this plan only names the shape. |
</threat_model>
