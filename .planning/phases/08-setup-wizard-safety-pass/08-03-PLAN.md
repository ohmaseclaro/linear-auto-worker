## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| Operator terminal → wizard process | The operator selects teams/projects/repos and optionally pastes a Slack webhook URL |
| Wizard process → Linear GraphQL API | `teams()`/`projects()` reads, using the already-admin-validated client from 08-02 — no new credential surface here |
| Wizard process → in-memory `existing` config | Re-run mode trusts the config file already on disk as the starting point for edits |

## STRIDE Threat Register

| Threat ID | Category | Component | Severity | Disposition | Mitigation Plan |
|-----------|----------|-----------|----------|-------------|-----------------|
| T-08-09 | Information Disclosure | `promptOneMapping` (Slack URL display) | medium | mitigate | A Slack incoming-webhook URL is bearer-secret-shaped (posting to it needs no other auth); re-run mode masks it to host-only when redisplaying an existing mapping rather than echoing it in full |
| T-08-10 | Tampering | `buildMappings` (re-run edit) | low | mitigate | "Keep as-is" mappings are returned by reference/deep-copy untouched — no code path can partially mutate a mapping the operator did not choose to edit |
| T-08-11 | Information Disclosure | `listMappingCandidates` | low | accept | Team/project names are printed to the operator's own terminal only; not secret, not transmitted elsewhere |

No new package-manager install task exists in this plan — `@linear/sdk@93.0.1` and
`@inquirer/prompts` are already sourced in `research/STACK.md`.
