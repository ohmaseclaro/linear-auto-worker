<objective>
Complete the agent invocation surface: the flag list, the child environment, and the
prompt trust boundary — plus the tests that make each of the three quiet
misconfigurations fail loudly if anyone reintroduces them.

`04-CONTEXT.md`'s `<specifics>` is the whole brief for this plan: **all three `claude -p`
misconfigurations fail quietly with exit 0, and every one needs a test that would catch
it.** A test suite that only proves the happy path is worth nothing here, because the
happy path and every failure mode are both `exit 0`.

Purpose: this is where the product's most likely failure lives. A run that produces
nothing and reports success is worse than a crash, and three separate flag mistakes all
produce exactly that.
Output: three modules complete with three test files, one manual probe script, and the
operator-facing trust document.

## The amendment this plan implements

`04-CONTEXT.md` D-01 was amended after the research probes and its original wording is
still in the file below the amendment. **The amended wording binds.** The mode alone was
measured to deny the `Write` tool with `decision_reason_type: "mode"`, create nothing, and
exit 0 with `is_error: false` — reaching trap T1 through the very flag chosen to avoid T1.
The same probe with `--allowedTools "Write" "Edit" "Bash"` had zero denials and produced a
real git commit.

D-15 was amended the same way: the child env is an **allowlist**, because 22 inherited
`CLAUDE*` variables flipped an otherwise-succeeding probe into an `asyncAgent` denial
(T28). A two-key delete cannot anticipate them.

    `prompt.test.ts`:
    - Each stripped class, one assertion apiece, written with `\u` escapes: a C0 control,
      a C1 control, a zero-width space, a zero-width joiner, a right-to-left override, a
      byte-order mark, and a Unicode tag character. None survive.
    - Tab, newline and carriage return **do** survive — stripping them would corrupt every
      normal multi-line ticket body, and a sanitizer that mangles ordinary tickets gets
      removed by the next person to debug one.
    - A ticket body containing the closing form of the untrusted-data delimiter cannot
      terminate the delimiter early — assert the assembled prompt still has one balanced
      pair around the ticket text.
    - The assembled prompt contains the commit-only instruction, and it appears **outside**
      the delimited region.
    - Both layers are applied: a body containing a plainly-worded instruction override
      (the classic "disregard everything above" shape) survives stripping verbatim —
      proving stripping alone is insufficient — yet appears only inside the delimiter,
      proving the second layer is what handles it.
