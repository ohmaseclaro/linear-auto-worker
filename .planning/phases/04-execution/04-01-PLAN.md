## AMENDED DECISIONS — the research reversed three of them

`04-CONTEXT.md` carries superseded text below its amendments. These four are what binds:

| Amendment | What changed |
|---|---|
| **D-01** | `dontAsk` **alone** denies `Write` and exits 0 — trap T1 reached through the flag chosen to avoid T1. It is only safe as `dontAsk` **plus** `--allowedTools "Write" "Edit" "Bash"` plus `--permission-prompts none` (T27). |
| **D-15** | The child env is an **allowlist**, not a two-key delete. 22 inherited `CLAUDE*` vars cause an `asyncAgent` denial (T28). |
| **D-10** | `SIGINT` does **not** reap the tree — it kills only the group leader. Escalation to `SIGTERM` on the group with liveness checks between steps is mandatory (T29). Plan 05 owns this; the tracer must not pretend `child.kill()` works. |
| **execa 10** | Has no `.on()`. `PITFALLS.md`'s Pitfall-5 sample is `node:child_process` code and crashes on an execa handle (T30). |

echoed on event #0, sixteen events before `system/init` (D-04 vindicated). `--json-schema`
survives `--resume`. `system/init.skills` is a flat `string[]`, so the D-05 assertion is

## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| Linear issue text -> agent prompt | Any workspace member can file an issue; its title and description become instructions to an agent holding shell and filesystem access on the operator's personal machine. This is the highest-severity boundary in the milestone. |
